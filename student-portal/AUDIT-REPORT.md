## Accessibility features used

- Heading order h1 -> h2 -> h3
- Every form field has a label linked with for and id
- fieldset and legend for radio buttons and checkboxes
- lang attribute, viewport and description meta tags
- Good colour contrast and visible focus outline for keyboard users
